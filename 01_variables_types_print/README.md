# 変数・型・print

PC-LABOのためのPython入門シリーズ第1回。変数とデータ型（int, str, bool）、四則演算・比較演算子、f-stringの書式指定（`:08b`, `:3d`など）を、バイト⇔ビット変換プログラムを通して確認する。

対応記事：PC-LABOを試すためのPython入門（第1回）～変数・型・print～

## 実行方法

```
cd 01_variables_types_print
python3 variables_types_print.py
```

## 確認していること

- 変数の作り方と、int / str / bool の3つの基本型
- 四則演算子（+ - * /）と比較演算子（== > <）
- f-stringの書式指定子（`:3d`は10進数を3桁幅で、`:08b`は2進数を8桁0埋めで表示）
- 関数定義（def）を使った、バイト数⇔ビット数の変換
